# PitinGuessr

Угадайте место в России по Яндекс.Панорамам. Два режима:

- **Один город** — любой из 1070 городов России, панорамы строго внутри его границ;
- **Вся Россия** — случайные места по всей стране, как в GeoGuessr.

5 раундов, до 5000 очков за раунд. Без регистрации и сервера — только браузер.

## 1. Вставьте ключ Яндекса

Откройте **`src/config.ts`** и впишите ключ между кавычками:

```ts
export const YANDEX_MAPS_API_KEY = 'ваш-ключ';
```

Ключ: https://developer.tech.yandex.ru/services/ → «JavaScript API» → бесплатный тариф.
Там же можно поменять название игры (`GAME_TITLE`).

## 2. Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

## 3. Публикация на GitHub Pages (автоматически)

В проекте уже есть `.github/workflows/deploy.yml` — GitHub сам соберёт и опубликует сайт.

1. Создайте репозиторий на github.com (Public), например `pitinguessr`.
2. Загрузите в него все файлы проекта **кроме** `node_modules` и `dist`.
3. Settings → Pages → Source: **GitHub Actions**.
4. Через 1–2 минуты сайт будет по адресу `https://ВАШ_ЛОГИН.github.io/pitinguessr/`.

Каждое изменение файлов в репозитории автоматически обновляет сайт.

## 3б. Публикация вручную (Netlify и др.)

```bash
npm run build
```

Готовый сайт появится в папке **`dist`** — это обычные статические файлы, их можно выложить на любой хостинг.

**Проще всего — Netlify Drop:** откройте https://app.netlify.com/drop, войдите и перетащите туда папку `dist`.
Через несколько секунд получите адрес вида `https://имя.netlify.app`.

Другие варианты: GitHub Pages, Vercel, Cloudflare Pages, любой обычный хостинг (загрузите содержимое `dist`).
Сборка использует относительные пути, поэтому работает и в подпапке.

### Обязательно после публикации

В кабинете Яндекса → «Ключи» → ваш ключ → **«Ограничение по HTTP Referer»** добавьте:

```
имя.netlify.app
localhost
```

Ключ JS API всегда виден в коде сайта — это нормально. Ограничение по адресу не даёт использовать его на чужих сайтах.

### Лимит бесплатного ключа

Бесплатно — 100 запросов к панорамам в сутки на ключ (общие для всех игроков сайта).
Это примерно 4–15 игр в день. Для большего нужен платный тариф Яндекса.

## Структура

```
src/
  config.ts   ← ключ API и название игры
  data/       индекс городов (Wikidata)
  map/        загрузка API, карта для угадывания
  panorama/   поиск случайной панорамы, плеер без подсказок
  game/       раунды, очки, режимы «город» и «Россия»
  ui/         экраны
  utils/      геометрия (Turf.js), форматирование
public/data/  границы городов (24 файла part-XX.json) (OpenStreetMap, © участники OSM, ODbL) и России
```
